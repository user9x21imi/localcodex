# Дисковая подкачка и длинный контекст

Windows: установщик записывает состояние файла подкачки в logs/swap.json. Если системное управление выключено, запуск Install.ps1 -EnableSystemSwap из PowerShell администратора включает его. После изменения может потребоваться перезагрузка. Настройка общесистемная; установщик не задаёт произвольный огромный размер файла.

macOS: swap управляется системой автоматически. Установщик и запуск сохраняют sysctl vm.swapusage в logs/swap-macos.txt. Не требуется создавать отдельный swap-файл, отключать защиту или изменять dynamic_pager. Нулевое использование swap при достаточной RAM нормально. На загрузочном диске должно оставаться свободное место.

Подкачка поддерживает оперативную память, но медленнее RAM. Она не добавляет VRAM и не увеличивает архитектурное окно контекста. Для длинных задач агент использует автоматическое сжатие истории, подбор размера контекста при запуске и адаптивный режим рассуждения. Fast/Max Power сохраняются; максимальный режим ограничен доступной памятью. При нехватке памяти полезнее уменьшить контекст или перенести часть слоёв на CPU, чем увеличивать swap бесконечно.

На текущем Windows ПК системное управление уже включено, выделено 13824 МБ. Изменение настройки не потребовалось. Выполнение на MacBook пока не проверено.
