# LocalCodex 0.2.0 preview

Локальный ИИ-агент для Windows: OpenCode **2.1.4**, gpt-oss-20b, локальное зрение, инструменты файлов и PowerShell, управление интерфейсом через Windows MCP. Отдельный установщик Apple Silicon пока экспериментальный.

Это самостоятельная сборка на открытых компонентах, не официальный продукт OpenAI. Качество локальной модели отличается от облачных Codex/ChatGPT; проверяйте её действия и выводы.

## Установка Windows

Скачайте ZIP из Releases, распакуйте и запустите `Install.cmd`. По умолчанию всё устанавливается в `C:\LLM`. Другой диск: `Install.cmd -Root D:\LLM`. Требуется Windows x64, интернет для загрузки около 14 ГБ моделей и зависимостей, минимум 30 ГБ свободного диска. Установщик проверяет SHA-256 моделей и бинарных архивов.

Проверенная машина: RTX 5070 Ti 16 ГБ, Ryzen 9950X, RAM 32 ГБ. Для других видеокарт настройка эвристическая. При нехватке VRAM используются частичная выгрузка слоёв на CPU и меньший контекст; скорость падает. AMD/Intel и многокарточные системы не проверены.

Запуск: `C:\LLM\localcodex.cmd`; в новом терминале — `localcodex`. Старый запуск V1 сохраняется как `localcodex-v1.cmd`, история V1 остаётся отдельно.

Дополнительные параметры:

```powershell
pwsh -File .\Install.ps1 -Root C:\LLM -Voice -AgentChannel -EnableDelegation
# Необязательное автоматическое разрешение действий:
pwsh -File .\Install.ps1 -Root C:\LLM -Yolo
```

По умолчанию действия требуют разрешения. `-Yolo` даёт широкие права инструментам от имени текущего пользователя. Голосовой ввод `-Voice` использует Handy/Parakeet локально: F5, вставка текста, отправка Enter вручную. Запустите `voice\Handy\handy.exe`, если он ещё не работает.

## Режимы, нагрузка и контекст

Auto выбирает усилие рассуждения по запросу, длине истории и ошибкам инструментов. `/fast задача` и `/max задача` задают режим для задачи. Профиль памяти при запуске: `localcodex -Mode Fast` / `-Mode MaxPower` / `-Mode Auto` в PowerShell-функции либо `pwsh -File C:\LLM\agent-v2.ps1 -Mode Fast`.

Заголовок вкладки показывает вращающийся индикатор из точек во время работы и 🔔 после завершения (при ошибке — ⚠). Строка статуса дополняет интерфейс: анимация работы, Auto/Fast/MaxPower, low/medium/high, GPU %, свободная VRAM, направление связи с агентами. `/localstatus` открывает подробности. GPU % — загрузка всего устройства, не процент выполнения задания. На Mac метрика GPU пока недоступна и отображается прочерком.

Контекст подбирается под доступную память при запуске сервера; история автоматически сжимается. Max Power не означает бесконечный контекст или постоянные 100% GPU. Подробности подкачки: [SWAP-RU.md](SWAP-RU.md).

## Связь с другими агентами

Установщик спрашивает, включить ли функцию. При каждом интерактивном запуске — отдельный вопрос для текущего сеанса. Ответ «нет» отключает входящие обращения и исходящее делегирование в этом сеансе. Установленные агенты обнаруживаются через `agent_list`. Поддержаны адаптеры Codex/Claude/Gemini, GUI-only Antigravity/agy только обнаруживаются. Реально проверен Codex; Claude/Gemini требуют отдельной проверки и авторизации.

Внешний агент использует свой аккаунт и лимиты. Секреты не следует включать в передаваемую задачу. Codex вызывается в read-only режиме; результат нужно проверить. Рекурсивное делегирование запрещено.

Локальный канал слушает только `127.0.0.1:8099`, требует случайный токен из `config-v2/channel-token`. Файл обнаружения: `state-v2/agent-discovery.json`. Для других клиентов есть MCP-мост `channel/mcp.mjs`; он читает токен локально.

Регистрация в установленном Codex CLI (запускать после установки Node.js):

```powershell
codex mcp add localcodex -- node C:\LLM\channel\mcp.mjs C:\LLM
```

Сначала запустите LocalCodex и разрешите связь. MCP-инструменты: `localcodex_status`, `localcodex_ask`, `localcodex_result`. Произвольные входящие задачи получают права самого LocalCodex; токен храните приватно.

## macOS preview

Только Apple Silicon, минимум 16 ГБ unified memory, рекомендуется 24–32 ГБ. Нужен Node.js; если установлен Homebrew, установщик может поставить Node автоматически.

```bash
bash macos/install.sh "$HOME/LLM"
"$HOME/LLM/localcodex"
```

Используются Metal, те же модели, режимы и канал агентов. Swap регулирует macOS автоматически. Запуск на физическом Mac пока **не проверен**. Windows MCP и установщик F5-голоса на Mac отсутствуют; macOS GUI через shell/osascript требует системных разрешений и тоже не проверен. Intel Mac пока не поддерживается.
