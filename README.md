# LocalCodex 0.2.0 preview

Локальный ИИ-агент для Windows: OpenCode **2.1.4**, gpt-oss-20b, локальное зрение, инструменты файлов и PowerShell, управление интерфейсом через Windows MCP. Отдельный установщик Apple Silicon пока экспериментальный.

Это самостоятельная сборка на открытых компонентах, не официальный продукт OpenAI. Качество локальной модели отличается от облачных Codex/ChatGPT; проверяйте её действия и выводы.

## Установка Windows

Скачайте **LocalCodex-Windows-v0.2.0.zip** из Releases, распакуйте и запустите `Install.cmd`. По умолчанию всё устанавливается в `C:\LLM`. Другой диск: `Install.cmd -Root D:\LLM`. Требуется Windows x64, интернет для загрузки около 14 ГБ моделей и зависимостей, минимум 30 ГБ свободного диска. Установщик проверяет SHA-256 моделей и бинарных архивов.

Проверенная машина: RTX 5070 Ti 16 ГБ, Ryzen 9950X, RAM 32 ГБ. Для других видеокарт настройка эвристическая. При нехватке VRAM используются частичная выгрузка слоёв на CPU и меньший контекст; скорость падает. AMD/Intel и многокарточные системы не проверены.

Запуск: `C:\LLM\localcodex.cmd`; в новом терминале — `localcodex`. Старый запуск V1 сохраняется как `localcodex-v1.cmd`, история V1 остаётся отдельно.

Дополнительные параметры:

```powershell
pwsh -File .\Install.ps1 -Root C:\LLM -Voice -AgentChannel -EnableDelegation
# Необязательное автоматическое разрешение действий:
pwsh -File .\Install.ps1 -Root C:\LLM -Yolo
```

По умолчанию действия требуют разрешения. `-Yolo` даёт широкие права инструментам от имени текущего пользователя. Голосовой ввод `-Voice` использует Handy/Parakeet локально: F5, вставка текста, отправка Enter вручную. Запустите `voice\Handy\handy.exe`, если он ещё не работает.

## Режимы, нагрузка и контекст

Auto выбирает усилие рассуждения по запросу, длине истории и ошибкам инструментов. `/fast задача` и `/max задача` задают режим для задачи. Профиль памяти при запуске: `localcodex -Mode Fast` / `-Mode MaxPower` / `-Mode Auto` в PowerShell-функции либо `pwsh -File C:\LLM\agent-v2.ps1 -Mode Fast`.

Заголовок вкладки показывает вращающийся индикатор из точек во время работы и 🔔 после завершения (при ошибке — ⚠). Строка статуса дополняет интерфейс: анимация работы, Auto/Fast/MaxPower, low/medium/high, GPU %, свободная VRAM, направление связи с агентами. `/localstatus` открывает подробности. GPU % — загрузка всего устройства, не процент выполнения задания. На Mac метрика GPU пока недоступна и отображается прочерком.

Контекст подбирается под доступную память при запуске сервера; история автоматически сжимается. Max Power не означает бесконечный контекст или постоянные 100% GPU. Подробности подкачки: [SWAP-RU.md](SWAP-RU.md).

## Связь с другими агентами

Установщик спрашивает, включить ли функцию. Выбранная при установке настройка применяется автоматически при запуске. Команда `/agent communication` включает/выключает входящие обращения и исходящее делегирование и сохраняет выбор для следующих запусков. Повторного вопроса при старте нет. Установленные агенты обнаруживаются через `agent_list`. Поддержаны адаптеры Codex/Claude/Gemini, GUI-only Antigravity/agy только обнаруживаются. Реально проверен Codex; Claude/Gemini требуют отдельной проверки и авторизации.

Внешний агент использует свой аккаунт и лимиты. Секреты не следует включать в передаваемую задачу. Codex вызывается в read-only режиме; результат нужно проверить. Рекурсивное делегирование запрещено.

Локальный канал слушает только `127.0.0.1:8099`, требует случайный токен из `config-v2/channel-token`. Файл обнаружения: `state-v2/agent-discovery.json`. Для других клиентов есть MCP-мост `channel/mcp.mjs`; он читает токен локально.

Регистрация в установленном Codex CLI (запускать после установки Node.js):

```powershell
codex mcp add localcodex -- node C:\LLM\channel\mcp.mjs C:\LLM
```

Сначала запустите LocalCodex с включённой связью (при необходимости `/agent communication`). MCP-инструменты: `localcodex_status`, `localcodex_ask`, `localcodex_result`. Произвольные входящие задачи получают права самого LocalCodex; токен храните приватно.

## macOS preview

Скачайте отдельный **LocalCodex-macOS-v0.2.0.zip**, распакуйте и откройте `Install-macOS.command`. Подробности: [README-macOS.md](README-macOS.md).

Только Apple Silicon, минимум 16 ГБ unified memory, рекомендуется 24–32 ГБ и 30 ГБ свободного диска. Node.js устанавливается автоматически внутри папки LocalCodex, Homebrew не требуется. После установки откройте `~/LLM/Start-LocalCodex.command`.

Проверка ARM runtime входит в CI; полная генерация модели на MacBook и macOS GUI ещё не проверены. Intel Mac и Windows-установщик F5-голоса на Mac пока не поддерживаются.

## Проверки и лицензии

[VALIDATION.md](VALIDATION.md) перечисляет выполненные проверки и ограничения. Для разработки: `cd migration-v2`, `npm ci`, `npx tsc --noEmit`; из корня `node tests/loop-guard.mjs`. Сборка не содержит моделей, личных чатов, токенов и пользовательских скриншотов. Компоненты и лицензии: [THIRD_PARTY.md](THIRD_PARTY.md).

### Язык, контекст и поиск
Правила пользователя хранятся в config-v2/AGENTS.md внутри папки установки; плагин перечитывает их при запросах. Русский язык закреплён также на уровне основного запроса и сжатия истории. После сжатия сохраняются последняя просьба и краткие результаты веб-инструментов. Служебная сводка не считается ответом пользователю.

Адаптер поиска использует официальный анонимный MCP Exa (https://exa.ai/mcp); поисковые запросы передаются Exa и действуют его ограничения. После двух успешных поисков агент должен прочитать первоисточник, прежде чем искать дальше. Веб-инструмент после двух ошибок временно отключается до следующего сообщения пользователя. Большие текстовые ответы сокращаются, полный вывод сохраняется локально в logs.
