# LocalCodex для macOS — Apple Silicon preview

## Установка

1. Скачайте **LocalCodex-macOS-v0.2.0.zip** из этого релиза и распакуйте.
2. Откройте папку `LocalCodex-macOS`, затем `Install-macOS.command` двойным кликом. Если macOS блокирует открытие, откройте Терминал в этой папке и выполните `bash Install-macOS.command`.
3. Установщик загрузит Node.js, OpenCode **2.1.4**, Python, MLX/Core ML, llama.cpp для зрения и модели с проверкой контрольных сумм. Homebrew и sudo не нужны; Python ставится автоматически внутри папки LocalCodex.
4. Выберите, включать ли связь с другими агентами и автоматическое разрешение действий (YOLO). Связь затем переключается `/agent communication`, без вопросов при каждом запуске.

По умолчанию всё находится в `~/LLM`. Установка в другую папку: `bash Install-macOS.command /Volumes/External/LLM`. Не отключайте внешний диск во время работы.

## Запуск

Двойной клик по **`~/LLM/Start-LocalCodex.command`** либо команда:

```bash
"$HOME/LLM/localcodex"
```

Режимы при запуске: `"$HOME/LLM/localcodex" --fast` / `--max`; внутри чата — `/fast задача` и `/max задача`. Auto выбирает усилие по запросу и контексту. Заголовок вкладки показывает анимацию во время работы и 🔔 по завершении. `/localstatus` показывает состояние; GPU % на Mac пока недоступен. MLX и наличие Neural Engine показываются отдельно, без выдуманного процента NPU.

## Требования и возможности

- Apple Silicon M1 или новее. Intel Mac пока не поддерживается.
- Минимум 16 ГБ unified memory, рекомендуется 24–32 ГБ. На 16 ГБ память сильно ограничена, скорость может быть низкой. MLX использует общую память CPU/GPU.
- Минимум 25 ГБ свободного диска, рекомендуется 30 ГБ. Загрузка моделей — около 14 ГБ.
- Интернет нужен для первой установки, поиска в сети и обращения к внешним агентам. Генерация основной модели и зрение выполняются локально.
- Swap управляется macOS автоматически; состояние пишется в `logs/swap-macos.txt`. Swap не заменяет VRAM и не увеличивает предел контекста.
- Инструменты файлов и shell доступны. Для GUI через `osascript` нужны системные разрешения Accessibility/Screen Recording. Windows MCP и Windows-установщик голоса F5 на macOS не устанавливаются.
- Адаптеры внешних Codex/Claude/Gemini требуют отдельно установленного и авторизованного CLI и используют его лимиты. Если Codex обнаружен и связь выбрана при установке, MCP-мост регистрируется автоматически.

Это preview. CI проверяет установку и запуск ARM runtime без загрузки больших моделей. Полная генерация gpt-oss-20b, графический интерфейс и скорость на конкретном MacBook требуют проверки на самом устройстве.

## MLX и Neural Engine

Основная GPT-OSS-20B работает на **MLX GPU (Metal)**. Устанавливаются mlx 0.32.4, mlx-lm 0.32.2 и отдельные проверенные MLX-веса; копия основной GGUF-модели не скачивается.

**NPU / Apple Neural Engine — отдельный Core ML backend.** Для совместимых локальных Core ML моделей доступен инструмент `coreml_predict` с моделью и JSON-файлом входных признаков. Он задаёт `CPU_AND_NE`, исключая GPU, но Core ML сам выбирает CPU/ANE для операций. Это не перенос GPT-OSS на NPU и не доказательство 100% загрузки ANE.

Установщик проверяет доступные Core ML устройства и исполняет небольшой численный тест с политикой CPU_AND_NE. Результаты: `logs/apple-accelerators.json` и `logs/coreml-selftest.json`. В виртуальном CI Neural Engine может отсутствовать — CPU fallback отмечается явно. Для произвольного Core ML inference нужна совместимая `.mlpackage`/`.mlmodel`/`.mlmodelc`; готовая большая Core ML языковая модель в комплект не входит.
